# 進捗管理

プロジェクト計画書（[plan.md](../02_plan/plan.md)）に基づく、実施状況の記録を置く。

| 文書 | 内容 | 更新の目安 |
| - | - | - |
| [progress-report_2026-11-24.md](progress-report_2026-11-24.md) | 進捗報告書（時点ごとの状況、成果物、残課題） | 週次・節目ごとに、日付を付けて新規作成 |
| [change-log.md](change-log.md) | 変更・意思決定の記録（計画との差異とその理由） | 変更が生じたとき |
| [incident-log.md](incident-log.md) | 障害・不具合の記録（原因、対応、再発防止） | 障害が発生したとき |
| [test-log.md](test-log.md) | テスト・検証の記録（実施済み、未実施） | テストを行ったとき |

関連する実装側の文書は、リポジトリ [naspi](https://github.com/ehayato/naspi) の `docs/` にある。

- `docs/restic-restore-test.md`: 復元テストの手順と記録
- `docs/schedule.md`: 同期・バックアップの実行時刻と排他
- `docs/discord-bot.md`: スラッシュコマンドの再登録、通知チャンネル
